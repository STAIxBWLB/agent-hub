# Character data

The project owner approved the STAIx text-frame reduction for public distribution
and selected all four existing alternative concepts on2026-10-13. This repository's
MIT license applies to these hand-authored text frames. The STAIx sprite sheet
and generated concept image bytes are not included or loaded.

The alternatives gyul, lantern, cursor-cat and boxbot were reduced from the
owner's Higgsfield concept images described in issue280, generated on2026-10-10
with Recraft V4.1. No new generation or provider account operation was needed.
