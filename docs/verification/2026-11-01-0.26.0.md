## Known gaps, not blocking

- No local full test suite: heavy tests run off the workstation, and the release PR's exact-head CI is the gate. Each merged PR had its own exact-head CI green (see Reviews).
- No running-hub upgrade to 0.26.0, no live TUI launch and no live check of `ahub up` opening the default agents in a real terminal; those are covered only by tests with stubs.
- The scoped-upgrade guarantee (a project's recorded runtime survives restart) starts with 0.26.0 CLIs; an older published CLI ignores the record. This ceiling is documented in docs/operations.md.
- One single non-reproducible failure of test/terminal-launch-daemon.test.ts "#482 ..." was seen in a remote full run of #1051; it passed in reruns, in CI and on main, and is treated as a timing flake.
