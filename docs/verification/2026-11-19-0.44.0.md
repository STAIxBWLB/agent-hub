`node scripts/check-docs.mjs --require-fresh` reported 22 stale documents. The review is delta-scoped: each document was read against what the release commits change under its governing paths since its stamp, not reread in full, and a restamp here certifies that delta only. The changes are isolated check outcomes (#1558), restart snapshot bounds (#1562), read receipts and the shell write classifier (#1561), runtime prune under recovery coordination (#1565), control-write span accounting (#1566), the single CLI audit outcome (#1563), the snapshot cooldown (#1554), quota row sampling (#1568), external merge costs (#1569), the check backstop (#1567), auto-pull triggers (#1570), yielding intent screening (#1571), sandbox cache defaults (#1572), the agent-mem 0.30.0 pin (#1573) and the 0.44.0 version bump made in release preparation.

Added the same-turn and 16-hop span accounting with its lower-bound limit (#1566), the recovery-hold rules for runtime pruning (#1565), the Bun and npm cache defaults in the command temp dir (#1572) and the ten-minute snapshot cooldown (#1554), and corrected the `snapshot unavailable` log line, which a turn boundary now writes only when a cooldown starts. Its restart archive, quota row and agent-mem pin sentences were already updated by #1562, #1568 and #1573.

The `quota` row was already updated by #1568.

- docs/dogfood.md: the opt-in auto pull row said at most one pull per capacity release; it is one per trigger and peer (#1570). Its other rows for these commits were added by the PRs that changed the sources.
- docs/agent-notes/daemon.md: added the CLI audit rule for commands that are not conductor operations (#1563) and the snapshot cooldown rule with its diagnostic (#1554); the task brief rule was updated by #1571.
