# 0.12.40 release verification

This record covers release preparation and source review. It does not claim publication, installation, a running-hub restart or native/live acceptance.

## Candidate

Version 0.12.40, control protocol 16 (unchanged; the daemon adds the `terminal_owner` and `cli_audit_delegated` features), from merged main. The person directed a bug-fix release on 2026-10-20 ("find the bug-fix issues, assign and implement them; include every bug fix in this release", then "finish and merge every PR, then release").

- Delivery and tasks: held task offers settle once the recipient owns and accepted the task (#434, PR #578); capacity-only declines are not lasting exclusions and planner-pull refusals name the cause (#531, PR #580); overlap findings stay within one repository, with `refs.repo` on propose and accept (#476, PR #583); Pi and the local worker report a hop-capped reply as not delivered (#550, PR #582).
- Recovery and launch: terminal records bind the live native owner and connected orphaned panes get reattach guidance (#482, PR #573); the Jcode TUI launcher records no managed terminal (#564, PR #565); `--print-command` names a mismatched session option (#574, PR #577); Jcode TUI review follow-ups (#559, PR #568).
- Jcode operations (#572, PR #575): a busy Jcode takes an `important` message into its running turn over its own socket (the hub never cancels a turn), an advisory when the main checkout is on a branch, an `ahub init` line that ends the turn after `hub_task_done`, and doctor lists the extra MCP servers the owned Jcode loads.
- Runtime: the completion-check runner settles within a 1 s kill grace when a killed child's events never arrive, and ignores a late exit or a retained stop after settling (#558, PR #581); Claude's turn completion is found beyond the 4 MiB tail (#528, PR #566); a reconnect re-announces a changed tool list (#490, PR #569); delegated CLI audits need the daemon feature `cli_audit_delegated` (#410, PR #571); stale-launch Claude channel plugins are refused (#551, PR #560).
- Config and models: the `pet` block is accepted by the schema and live reload (#483, PR #567); doctor names routing parse errors (#563, PR #570); the Switchyard sidecar is retired for in-process routes (#553, PR #561); `ahub memory profile-check` is split-aware (#536, PR #579).
- Still open (unchanged from 0.12.39): live native clients, installed managed-Pi #418 AC8, #438 AC7, the native console settings leg (#439 AC5), real upgrades with reattach (#463) and with a managed terminal and cancelled rows (#478), a live fresh Codex review, a live split of a real memory home, the agy live TUI/account leg (#251), Kimi's interactive-TUI coexistence and usage checks (#533), Jcode's TUI with a personal account (#464) and a live Jcode tool call past the watchdog (#542).
- New open legs: a live steer of a busy Jcode turn with a real provider (#572; fakes only) and a real upgrade that exercises the `terminal_owner` record (#482).
- Not in this release: #576 (the daemon runs hot under open turns; profile first, hub task #263), #584 (a manager test can leak a process on Ubuntu CI), #434 T3 (live check).
