# 0.19.0 release verification

This record covers release preparation and source review. It claims no installation, no running-hub upgrade to 0.19.0 and no live TUI launch.

## Candidate

Version 0.19.0, built from merged main 08590801 (25 commits since v0.18.0, 8 of them `feat`). The release commits carry the version, the CHANGELOG section, the bundle (plugin 0.19.0, built with the pinned Bun 1.4.2 and the worktree's own frozen `node_modules`; against main the bundle differs only in its version string), the document corrections and the stamps. Control protocol stays 16; `@staix/agent-mem` is pinned at 0.10.0.

What changed (see `CHANGELOG.md` for the full list):
- Host-wrapper shell grants for the headless Claude implementer in `ask-when-needed`, with code gates confined away from project Git metadata (#845: #857).
- Code-only review scope and evidence-only verdicts (#852: #853); optional `model` for the headless Claude implementer (#844: #848).
- Agent CLI drift: a daily public-source watch and a planner notice for unverified installed versions (#849, #855); a native version gate for Pi (#843: #847); new verified versions for agy, Jcode, kimi-review, headless Qwen and claude-implementer (#850, #851, #856, #858, #859).
- Planner work-ready notices (#785: #842) and the lockfile-keyed dependency volume for the remote runner (#793: #846).
- Sandbox protection for submodule git dirs and `config.worktree` (#862, #866), the Qwen background-task notice fix (#861), conductor error preservation (#812: #839).
- CI: the suite watchdog stops on lost progress (#516: #870) and CI admission retries a transient GitHub 5xx or 429 (#872: #873).
