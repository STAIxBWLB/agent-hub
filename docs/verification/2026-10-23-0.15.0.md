# 0.15.0 release verification

This record covers release preparation and source review. It claims no publication, installation, running-hub restart or live TUI launch.

## Candidate

Version 0.15.0, built from merged main at 12dd7b66. The person directed the release on 2026-10-23. It includes features, so the minor version is bumped (AGENTS.md, Releasing step 1).

- Daemon responsiveness (#719, #741): the hot paths read only pending delivery-journal state, and a launch connect retries within a bound with `hub busy, retrying`. On this machine a 0.14.0 daemon sat at about 100% CPU. That also made codex-review's 2 s isolation proof commands time out, and the hub's 2 s claude-mem saves.
- Structural config editing from the console and a dashboard settings session: validated, previewed, audited and restart-aware (#689, #734).
- Claude implementer instances:
  - a terminal instance's execution root is verified before it owns write tasks (#525-5, #742);
  - a headless implementer has per-task sessions and person approvals that fail closed (#525-4, #747).
- Always-ask action classes are enforced in the Claude PreToolUse hook and in ACP `request_permission`, with a session class budget (#636 slice 2, #743).
- Routing:
  - the planner walk and I-2 reviewer independence in `assign()`, shown by `ahub route explain` (#525-3, #744);
  - no write-class task for a person-started Claude instance before 525-5 (#735, #738).
- Review evidence:
  - acceptance-criteria ids in the review request and on the verdict (#507, #745);
  - deliverable records bound to content hashes (#509 AC1, AC2, AC4, #746).
- Kimi tokens counted from its session wire log (#285 phase 2, #740).
- A finding carried to a follow-up of the same PR or branch is not a recurrence (#736, #737).
- `ahub backlog list` prints a table (#399, #739).
- Still open:
  - #636 slice 3 (#313, PR #750);
  - #285 phase 4 (#315, PR #749);
  - the memory sync log fix (#401, PR #748);
  - agent-mem#13 P3 (#391, agent-mem PR #34) and P4;
  - #525-2 and #525-6.
