## Retirement in this release

The version bump closes the #481 deprecation window (`RETIRED_WORKFLOW_FROM = "0.13.0"`). `sdlc.workflow` no longer loads, and the `phase` receipt name is refused. Three workflow tests that used `phase` inside the window failed on the first release CI run. They now assert the refusal and record `criteria`, and their other assertions are unchanged. This project uses neither setting. `local.bash_network: "direct"` is not version-gated and only warns, so its removal moves to a later release. `docs/agent-notes/tests.md` was rechecked against that test change (no rule affected) and restamped at the test commit.

## Release mechanics

Merge the release PR with a merge commit, because the stamps name release-branch commits. Run `node scripts/check-docs.mjs --require-fresh` on the merged main, then tag `v0.13.0`. Afterwards read the published version back from the registry with a cache-busting request.
