# Pi localhost listener decision

Hub task 967, Refs #1447 T5b. Decision: no listener grant is shipped on the
evidence available. Pi's existing Seatbelt profile and external egress policy
remain unchanged. This is a decision about the tested mechanisms, not a claim
that every possible mechanism is impossible.

## Evidence

The native macOS arm64 experiments from hub task 949 used Bun 1.4.2 and no live
Pi session, model or account. Their source is preserved at commit
`ad4ae27118a05bdc6283ba8f6bdd621c2848dee2`; the observations are recorded in
the T5b issue comment on #1447.

- Local `localhost` matchers for bind and inbound allowed a wildcard bind. The
  experiment did not prove that a non-loopback peer could not reach it.
- Local `localhost` bind with remote `localhost` inbound and outbound refused
  the localhost listener positives. The unrestricted control reached the
  fixture-owned non-loopback interface, but the restricted listener did not
  start. This is not evidence of a safe usable listener.
- The raw socket egress checks reported kernel refusal for non-loopback egress
  under both the existing and experimental profiles. They do not establish
  inbound isolation.

No new native run was made for this decision. In particular, the required
negative connection from a non-loopback interface to a working restricted
listener remains unproven. The failed second combination is not retried without
new evidence.

## Available separate check path

For an eligible, non-private accepted task, `hub_check_start` can run permitted
tests on an exact Git ref in the opt-in isolated container runner. Its receipt
names the platform and outcome; it is Linux evidence, not proof that a listener
works or is isolated in Pi's macOS sandbox. Availability depends on configured
runner admission, and no live Pi receipt is claimed here. See `docs/operations.md`
for the runner's bounds. Listener-dependent tests remain outside Pi-local
focused checks until a distinct mechanism supplies the native positive and
non-loopback denial proof required by T5b.
