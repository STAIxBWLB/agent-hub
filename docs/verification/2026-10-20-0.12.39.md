# 0.12.39 release verification

This record covers release preparation and source review. It does not claim publication, installation, a running-hub restart or native/live acceptance.

## Candidate

Version 0.12.39, control protocol 16 (unchanged; the daemon adds the `native_tui_launch` feature), from merged main `f9df83d6`. The person directed the release on 2026-10-20 ("finish the open PRs and release the next version").

- #464 (PR #557, hub task #246): `ahub jcode` opens jcode's native TUI by default, attached to the hub-driven ACP session.
  - The console-only `native_tui_launch` hands the launch tuple only to the person's launcher, after a bounded read-only proof that the session is saved.
  - The launcher waits with one fixed line and opens the TUI once the session is saved; Ctrl-C ends only the wait.
  - Start mode resolves from the flag, then the accepted daemon mode, then file/default; `--mode headless` is unchanged.
  - J1.4 is amended: jcode 0.98.1 saves a session only after its first real prompt.
- #542 D4 (PR #547, hub task #245): an announced ACP tool call that has not completed or failed keeps the turn alive up to a 30 min tool ceiling (never below `watchdog_ms`). The watchdog re-arms only for the remaining ceiling.
- #548 (PR #552, hub task #247): the MLX test fixtures take a free loopback port.
- Still open (unchanged from 0.12.38): live native clients, installed managed-Pi #418 AC8 (#142), #438 AC7, the native console settings leg (#439 AC5), real upgrades with reattach (#463) and with a managed terminal and cancelled rows (#478), a live fresh Codex review with a real account, a live split of a real memory home (#536), the agy live TUI/account leg (#251), and Kimi's interactive-TUI coexistence and usage checks (#533).
- New open legs:
  - Jcode's TUI with a personal account, a real provider and hub-tool calls (#464). The receipt covers only an isolated HOME with a loopback fixture provider (docs/verification/2026-10-20-jcode-tui-0.98.1.md).
  - A live Jcode tool call held past the inactivity watchdog (#542); only fake-ACP tests cover it.
- Follow-ups: #559 (review nits of #557), #558 (macOS `runCheck` hang), #555 (agy native reads into Facts).
