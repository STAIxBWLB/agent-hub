# 0.14.0 release verification

This record covers release preparation and source review. It does not claim publication, installation, a running-hub restart or a live TUI launch.

## Candidate

Version 0.14.0, from merged main at 11623553. On 2026-10-23 the person directed the release. It includes features, so the minor version is bumped (AGENTS.md, Releasing step 1).

- Roles capability per kind and form (#525-1, #725). A Claude channel instance may implement or verify in its own worktree. `planner` needs a kind that can plan, both for instances and for `roles` entries keyed by an instance id. This repository's claude holds the implementer role.
- The dashboard Usage view (#683 U4, #726) and the task sheet's Code group (#684 phase 2c, #731).
- SDLC metrics and control bands (#481 S7, #730): `ahub sdlc metrics`, `hub_sdlc_metrics`, and `[bands.<metric>]` with the log, diagnose and propose tiers.
- The compact `ahub board` (#724, #728): one line per task, with `--full` keeping the wrapped layout.
- Fixes:
  - `ahub codex --as` for a headless reviewer (#720, #721);
  - reviewer start-failure cause classes (#722, #727);
  - issue identity linked at propose and accept (#723, #729);
  - reserved backlog pulls offered to their reserved peer (#718, #732).
- Still open:
  - #689, config editing;
  - #684 phases 3 and 4;
  - agent-mem#13 P3 (board #391) and P4 (#392);
  - #719, the post-upgrade daemon CPU (#386);
  - the release-metric bands and gates-run record (#481, recorded in the S7 amendment).
